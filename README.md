# 📡 每日信息差看板

一个**手机 + 电脑通用**的每日信息聚合看板:分类新闻 + 天气预报 + 全平台热搜,每天自动抓取更新,每条信息都带原文链接可溯源。

## 功能

- **分类新闻**:科技(AI / 计算机 / 生物 / 化学 / 药理)、实证科学、战争军事、电竞游戏、数码、财经宏观、社会民生、时政
- **天气预报**:珠海 + 澳门(可改)
- **全平台热搜**:微博 / 百度 / 知乎 / B站 / 今日头条 + 国外(Reddit / Hacker News / 谷歌趋势),**国外内容标题自动机翻成中文**
- **响应式**:手机、平板、电脑自适应,白天 / 夜间主题
- **自动更新**:GitHub Actions 每天定时抓取 3 次,无需本地开机

## 目录结构

```
infodiff/
├── config.mjs               # 配置:分类、信源、城市、热搜平台(在这里改)
├── fetch.mjs                # 抓取脚本:新闻 RSS + 天气 + 热搜 + 翻译
├── serve.mjs                # 本地预览服务器
├── site/                    # 前端(部署目录)
│   ├── index.html
│   ├── styles.css
│   ├── app.js
│   └── data/                # 抓取生成的 JSON(meta/news/weather/hot)
└── .github/workflows/update.yml   # 自动更新 + 部署
```

## 本地预览

需要 Node.js ≥ 18:

```bash
node fetch.mjs      # 抓取一次, 生成 site/data/*.json
node serve.mjs      # 启动预览, 打开 http://127.0.0.1:8787
```

## 部署到云端(手机 / 电脑随时随地看)

1. 注册一个 [GitHub](https://github.com) 免费账号(已有则跳过)。
2. 新建一个**公开**仓库(名字随意,例如 `infodiff`)。
3. 把整个 `infodiff` 文件夹内容推送到该仓库。
4. 在仓库 **Settings → Pages** 里,把 **Source** 选为 **GitHub Actions**。
5. 推送到 `main` 分支后,Actions 会自动跑一次;以后每天 3 次自动更新。
6. 打开 **Settings → Pages** 里的网址(形如 `https://用户名.github.io/infodiff/`),手机浏览器收藏即可。

> 手机访问:直接收藏该网址,无需装 App;电脑浏览器打开同一个网址,看到的是同一份数据。

## 自定义

改 `config.mjs` 即可:

- **天气城市**:修改 `CITIES`(城市名 + 经纬度)。
- **新闻分类 / 信源**:修改 `CATEGORIES`,信源可用直接 RSS(`url`)或谷歌新闻(`gnews: "关键词"`)。
- **热搜平台**:修改 `HOT_PLATFORMS`。
- **抓取条数 / 频率**:`OPTIONS` 与 `.github/workflows/update.yml` 里的 cron。

## 说明与注意

- 所有内容聚合自**公开信源**,每条带原文链接,点击即可溯源核实;本项目不生产内容、不站立场。
- 国外内容标题为**机器翻译**(页面标注「机翻」),仅供参考,请以原文为准。
- 个别信源可能临时限流或失效,脚本会自动跳过;某板块全部失败时会**沿用上一次数据**并标注。
- 谷歌新闻、谷歌趋势、谷歌翻译等源需在**能访问 Google 的网络**(如 GitHub 云端)运行;本地直连若失败属正常。

## 隐私

本工具为纯静态网页,不含任何跟踪脚本、不收集任何个人信息。
